# Module Analysis: commerce-payments

Review state: Partial detailed trace.

## Findings

Checkout quote requires exactly one course or bundle and allows up to 10 bump IDs; shared priceCheckout returns a read-only quote. Razorpay verification checks signature and fulfills through shared order service with retry; unfulfillable paid orders queue refund review; email is sent by winning fulfillment transition. Stripe webhook uses signature verification and returns 503 if credentials are not configured. Commerce Zod schemas define checkout, transaction, coupon, product fields.
