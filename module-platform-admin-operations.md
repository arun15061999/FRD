## Partial cross-layer findings

* Admin user listing query schema accepts role `admin|teacher|student`; status `active|suspended|deleted`; search max 200; parseable date ranges; sort field `created_at|full_name|email|last_login` default `created_at`; direction `asc|desc` default `desc`; page/limit parsed and bounded. Source comments establish user status is derived from `is_active` plus `deleted_at`, while last login comes from `auth.users.last_sign_in_at` (not `users.last_login`). Summary derives role/status counts, pending invites, flagged members, new-this-week, signed-in-24h/7d, and ever-signed-in. Evidence: `src/app/api/v1/admin/users/route.ts:20-55+`.
* Saved reports are admin/teacher only. List returns rows created by caller or shared; create validates name 1–255, description max 1,000, report type enum (`enrollment_summary`, `revenue_report`, `course_completion`, `student_activity`, `gradebook_export`, `certificate_issuance`, `forum_activity`, `exam_results`, `platform_analytics`), JSON config default `{}`, `is_shared` default false, and writes `created_by`. Evidence: `src/app/api/v1/reports/route.ts:8-56`.
